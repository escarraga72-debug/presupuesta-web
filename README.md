# Presupuesta · web pública

Páginas públicas de la app Presupuesta (Jasait Servicios S.L.):

- `index.html`: portada y descarga de la versión de pruebas para Android.
- `privacidad.html`: política de privacidad (enlace que pide Google Play).
- `condiciones.html`: condiciones de uso.
- `eliminar-cuenta.html`: cómo borrar la cuenta (enlace que pide Google Play).
- `version.json`: última versión publicada; la app lo consulta para avisar de actualizaciones.

El archivo `presupuesta.apk` de cada versión se publica en Releases. Enlace fijo a la última:
https://github.com/escarraga72-debug/presupuesta-web/releases/latest/download/presupuesta.apk
